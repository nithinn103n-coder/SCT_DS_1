# SKILLCRAFT – Task 1  
## Population & Demographic Data Analysis using Python

This project is part of **SkillCraft Technology – Data Science Task 1**.  
It demonstrates how to generate a dataset, perform exploratory data analysis, and visualize population distribution using Python.

---

## 📌 Project Overview

The project performs the following tasks:

1. Generates a **sample demographic dataset**
2. Saves the dataset as a CSV file
3. Loads the dataset using Pandas
4. Visualizes:
   - Age distribution
   - Gender distribution
   - Simulated population distribution by age (India-based)

---

## 🧰 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📂 Dataset Details

A synthetic dataset with **500 records** is created containing:

- **Age** (0–85)
- **Gender** (Male, Female, Non-Binary)
- **Country** (USA, India, UK, Canada, Germany)
- **Employment Status** (Employed, Unemployed, Student, Retired)

## 📊 Visualizations

### 1️⃣ Age Distribution
- Histogram with KDE curve
- Shows how age values are spread across the dataset

### 2️⃣ Gender Distribution
- Count plot
- Displays number of individuals by gender

### 3️⃣ Population Distribution Curve
- Simulated bell-shaped curve
- Highlights:
  - **0–20 years (Young population)**
  - **21–64 years (Working population)**
  - **65+ years (Elderly population)**
- Inspired by India’s population structure
- Median age considered: **28 years**
